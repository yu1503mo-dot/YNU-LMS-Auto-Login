# YNU LMS Auto Login

横浜国立大学のLMSへのログインを自動化するPythonプログラムです。

WindowsへのログオンをきっかけにMicrosoft EdgeでLMSを開き、保存したログイン情報とOutlookで受信した認証コードを利用して、ログイン操作を自動化します。

毎日の煩わしいログイン作業をなくすことを目的に作成しました。

## 主な機能

* ユーザーIDとパスワードをWindows資格情報マネージャーに保存
* auto_login_for_LMS_distribution.pyをタスクスケジューラに登録
* Windowsへのログオン時にLMSの自動ログインプログラムを実行
* Microsoft Edgeを起動し、LMSへのログイン情報を入力
* Outlookで受信した認証コードを取得し入力
* タスクスケジューラを利用して、次回以降のログオン時にも自動実行

## 動作環境

以下の環境を想定しています。

* Windows 10 / Windows 11
* Python
* Microsoft Edge
* Outlookのデスクトップ版（従来版）
* インターネット接続
* 横浜国立大学のLMSを利用できるアカウント

使用するPythonライブラリは以下のとおりです。

* Selenium
* keyring
* pywin32
* pyperclip

Pythonのバージョンや実行環境によっては、追加の対応が必要になる場合があります。

## 導入方法

### 1. ファイルをダウンロードする

1. [GitHubのリポジトリ](https://github.com/yu1503mo-dot/YNU-LMS-Auto-Login)を開きます。
2. 緑色の **Code** ボタンをクリックします。
3. **Download ZIP** を選択します。
4. ダウンロードしたZIPファイルを展開します。

Gitのインストールやコマンド操作に慣れていない場合は、この方法がおすすめです。

### 2. Pythonを用意する

Pythonがインストールされていない場合は、Pythonの公式サイトなどからインストールしてください。

[Python公式サイト](https://www.python.org/)

すでにAnacondaなどのPython環境を利用している場合は、その環境を使用することもできます。

### 3. コマンドプロンプトを開く

展開したフォルダを開き、エクスプローラーのアドレスバーに `cmd` と入力してEnterキーを押します。

表示されたコマンドプロンプトで、以下を実行します。

```powershell
python -m pip install -r requirements.txt
```

必要なライブラリがインストールされます。

`python` コマンドが認識されない場合は、PythonのインストールやPATHの設定を確認してください。

### 4. 初期設定を実行する

同じコマンドプロンプトで、次のコマンドを実行します。

```powershell
python set_up_for_autolog_LMS.py
```

画面の案内に従って、大学のユーザーIDとパスワードを入力してください。

入力した情報はWindows資格情報マネージャーに保存されます。**パスワードは入力時に画面に表示されます。** 周囲から見られない環境で入力してください。

初期設定が完了すると、タスクスケジューラに「YNU LMS Auto Login」というタスクが登録されます。

同名のタスクがすでに存在する場合、セットアップは既存のタスクを削除せずに終了します。

### 5. 自動実行を確認する

Windowsから一度サインアウトし、再度サインインするなどして動作を確認してください。

正常に設定されていれば、Windowsへのログオン時に自動ログインプログラムが起動します。

初回はMicrosoft EdgeやOutlookに関する確認画面が表示される場合があります。その場合は、必要な確認を手動で済ませてから、再度動作を確認してください。

## 自動実行を停止する方法

### 1. 自動実行のタスクを削除する

コマンドプロンプトまたはPowerShellで、次のコマンドを実行します。

```powershell
schtasks /Delete /TN "YNU LMS Auto Login" /F
```

これにより、Windowsへのログオン時に自動実行する設定が削除されます。

### 2. 保存した認証情報を削除する

タスクを削除しただけでは、保存したユーザーIDとパスワードは削除されません。

1. Windowsの検索欄で「資格情報マネージャー」を検索して開きます。
2. 「Windows資格情報」を選択します。
3. `YNUUniversityAutoLogin_User` と `YNUUniversityAutoLogin_Password` に対応する登録情報を探します。
4. 該当する認証情報を個別に削除します。

認証情報の表示名は環境によって異なる場合があります。削除する前に内容を確認してください。

自動実行を停止した後も、プログラムを手動で実行することはできます。

## トラブルシューティング

### 1. `python` コマンドが認識されない

「`python` は認識されていません」などのメッセージが表示される場合、Pythonがインストールされていないか、PATHが正しく設定されていない可能性があります。

**対処方法**

1. Pythonがインストールされているか確認してください。

2. コマンドプロンプトを開き、次のコマンドを実行してください。

   ```bash
   python --version
   ```

3. バージョンが表示されない場合は、Pythonのインストール状況や環境変数の設定を確認してください。

Anacondaを利用している場合は、Anaconda Promptから実行すると解決する場合があります。

### 2. ライブラリのインストールに失敗する

次のコマンドでエラーが発生する場合は、Python環境やインターネット接続を確認してください。

```bash
python -m pip install -r requirements.txt
```

**対処方法**

1. インターネットに接続できているか確認してください。
2. `python --version` でPythonが利用できるか確認してください。
3. エラーメッセージを確認し、必要に応じてPython環境を見直してください。

### 3. Microsoft Edgeが起動しない、またはログインできない

**考えられる原因**

* Microsoft Edgeがインストールされていない。
* LMSの画面や認証方式が変更された。
* ネットワーク接続に問題がある。
* ブラウザ操作中にエラーが発生した。

**対処方法**

1. Microsoft EdgeでYNU授業支援システムに手動でログインできるか確認してください。
2. Microsoft Edgeが最新版になっているか確認してください。
3. エラーメッセージが表示される場合は、その内容を確認してください。

大学側の画面や認証方式が変更された場合、プログラムの修正が必要になることがあります。

### 4. Outlookから認証コードを取得できない

本プログラムは、Outlookのデスクトップアプリを通じて認証コードを取得します。

**対処方法**

1. Outlookが利用できる状態になっているか確認してください。
2. 認証コードがメールで届いているか確認してください。
3. Outlookのアカウント設定やメールの受信状況を確認してください。
4. Outlookの初回起動時の確認画面などが表示されている場合は、画面の指示に従ってください。

Outlookの種類や設定によっては、認証コードを自動取得できない場合があります。

### 5. Windowsへのログイン時に自動実行されない

**対処方法**

1. Windowsの「タスク スケジューラ」を開いてください。
2. タスク スケジューラ ライブラリから `YNU LMS Auto Login` を探してください。
3. タスクが登録されているか、有効になっているか確認してください。
4. タスクを手動で実行し、動作するか確認してください。

タスクが登録されていない場合は、セットアップスクリプトを再実行する前に、同名のタスクがすでに存在していないか確認してください。

### 6. 解決しない場合

上記の方法で解決しない場合は、エラーメッセージを確認してください。

GitHubで報告する場合は、Pythonのバージョン、エラーの内容、発生した操作などを記載すると、原因を調べやすくなります。

**注意：** ログインID、パスワード、認証コード、個人情報などは、エラーメッセージやスクリーンショットに含めないでください。
