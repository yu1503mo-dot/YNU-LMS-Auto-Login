# YNU LMS Auto Login

横浜国立大学のLMSへのログインを自動化するPythonプログラムです。

WindowsへのログオンをきっかけにChromeでLMSを開き、保存したログイン情報とOutlookで受信した認証コードを利用して、ログイン操作を自動化します。

毎日の煩わしいログイン作業をなくすことを目的に作成しました。

## 主な機能

* ユーザーIDとパスワードをWindows資格情報マネージャーに保存
* auto_login_for_LMS_distribution.pyをタスクスケジューラに登録
* Windowsへのログオン時にLMSの自動ログインプログラムを実行
* Chromeを起動し、LMSへのログイン情報を入力
* Outlookで受信した認証コードを取得し入力
* タスクスケジューラを利用して、次回以降のログオン時にも自動実行

## 動作環境

以下の環境を想定しています。

* Windows 10 / Windows 11
* Python
* Google Chrome
* Outlookのデスクトップ版（従来版）
* インターネット接続
* 横浜国立大学のLMSを利用できるアカウント

使用するPythonライブラリは以下のとおりです。

* Selenium
* keyring
* pywin32
* pyperclip

Pythonのバージョンや実行環境によっては、追加の対応が必要になる場合があります。

## 導入方法

### 1. ファイルをダウンロードする

1. [GitHubのリポジトリ](https://github.com/yu1503mo-dot/YNU-LMS-Auto-Login)を開きます。
2. 緑色の **Code** ボタンをクリックします。
3. **Download ZIP** を選択します。
4. ダウンロードしたZIPファイルを展開します。

Gitのインストールやコマンド操作に慣れていない場合は、この方法がおすすめです。

### 2. Pythonを用意する

Pythonがインストールされていない場合は、Pythonの公式サイトなどからインストールしてください。

[Python公式サイト](https://www.python.org/)

すでにAnacondaなどのPython環境を利用している場合は、その環境を使用することもできます。

### 3. コマンドプロンプトを開く

展開したフォルダを開き、エクスプローラーのアドレスバーに `cmd` と入力してEnterキーを押します。

表示されたコマンドプロンプトで、以下を実行します。

```powershell
python -m pip install -r requirements.txt
```

必要なライブラリがインストールされます。

`python` コマンドが認識されない場合は、PythonのインストールやPATHの設定を確認してください。

### 4. 初期設定を実行する

同じコマンドプロンプトで、次のコマンドを実行します。

```powershell
python set_up_for_autolog_LMS.py
```

画面の案内に従って、大学のユーザーIDとパスワードを入力してください。

入力した情報はWindows資格情報マネージャーに保存されます。**パスワードは入力時に画面に表示されます。** 周囲から見られない環境で入力してください。

初期設定が完了すると、タスクスケジューラに「YNU LMS Auto Login」というタスクが登録されます。

同名のタスクがすでに存在する場合、セットアップは既存のタスクを削除せずに終了します。

### 5. 自動実行を確認する

Windowsから一度サインアウトし、再度サインインするなどして動作を確認してください。

正常に設定されていれば、Windowsへのログオン時に自動ログインプログラムが起動します。

初回はChromeやOutlookに関する確認画面が表示される場合があります。その場合は、必要な確認を手動で済ませてから、再度動作を確認してください。

## 自動実行を停止する方法

### 1. 自動実行のタスクを削除する

コマンドプロンプトまたはPowerShellで、次のコマンドを実行します。

```powershell
schtasks /Delete /TN "YNU LMS Auto Login" /F
```

これにより、Windowsへのログオン時に自動実行する設定が削除されます。

### 2. 保存した認証情報を削除する

タスクを削除しただけでは、保存したユーザーIDとパスワードは削除されません。

1. Windowsの検索欄で「資格情報マネージャー」を検索して開きます。
2. 「Windows資格情報」を選択します。
3. `YNUUniversityAutoLogin_User` と `YNUUniversityAutoLogin_Password` に対応する登録情報を探します。
4. 該当する認証情報を個別に削除します。

認証情報の表示名は環境によって異なる場合があります。削除する前に内容を確認してください。

自動実行を停止した後も、プログラムを手動で実行することはできます。

## 注意事項

* 本プログラムは、横浜国立大学の公式ソフトウェアではなく、個人が作成したものです。
* 大学のLMSや認証方式の変更により、動作しなくなる可能性があります。
* Outlookのデスクトップ版が適切に設定され、認証メールを受信できる必要があります。
* OutlookやWindowsのセキュリティ確認画面などが原因で、自動処理が中断される場合があります。
* 本プログラムは、ログイン操作を自動化するものであり、大学の認証を回避するものではありません。
* ユーザーIDとパスワードは、通常のログイン処理でLMSに送信されます。認証情報の管理には十分注意してください。
* 利用者自身の環境で動作を確認したうえで使用してください。
